# Свет-36 — калькулятор коммерческого предложения

Веб-приложение для менеджера магазина дизайнерского освещения «Свет-36»
([svet-36.ru](https://svet-36.ru)): ввод позиций, расчёт скидки, предпросмотр КП
и выгрузка в PDF / Excel с отправкой клиенту по ссылке.

## Возможности

- Клиент, объект, менеджер, способ оплаты и доставки, произвольные комментарии.
- Позиции: наименование, артикул, единица измерения, количество, цена за единицу
  и сумма (с возможностью ручной корректировки).
- Фотографии товаров: загрузка файлом, drag-and-drop или вставка из буфера обмена.
  Изображения сжимаются в браузере (canvas, до 1000 px, JPEG).
- Автоматический номер КП вида `С36-YYMM-NNN` и счётчик в `localStorage`.
- Скидка в процентах, срок действия (по умолчанию 3 дня), итоговая сумма «К оплате».
- Живой предпросмотр листа A4 в масштабе по ширине колонки.
- Экспорт:
  - **PDF** — pdfmake, встроенный кириллический шрифт Roboto, логотип, фото, таблица,
    реквизиты, номер КП в шапке, колонтитул со страницами;
  - **Excel** — ExcelJS, логотип и фото, закреплённая шапка, формулы `SUM`, настройки печати.
- Ссылка на КП: сериализация в URL hash (`#p=...`), кнопки «Скопировать», Telegram,
  WhatsApp, E-mail, Viber и Web Share. Фотографии в ссылку не попадают.
- Все расчёты выполняются в браузере — данные не уходят на сторонние серверы.
- Светлая и тёмная тема, автосохранение черновика, адаптивная вёрстка.

## Запуск

```bash
npm install
npm run dev      # локальная разработка
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
npm run lint     # oxlint
```

## Деплой

Сборка публикуется на GitHub Pages через `.github/workflows/pages.yml`
(ветка `main`). В `vite.config.ts` указан `base: './'`, поэтому приложение
корректно работает и по пути `/svet36-kp-calculator/`, и на собственном домене.

## Структура

```
src/
  components/   интерфейс: шапка, форма клиента, позиции, опции, предпросмотр, панель действий
  lib/          расчёты, форматирование, номер КП, localStorage, сжатие фото, share, PDF, Excel
  state/        useProposal — состояние предложения, CRUD позиций, автосохранение
  types.ts      модели данных
  assets/       логотип
public/         favicon
```

Реквизиты компании берутся из `src/lib/company.ts` и редактируются прямо
в интерфейсе (данные хранятся локально в браузере).
